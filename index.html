Опис продукту

InsideScoop — веб-сервіс для швидкого пошуку та перегляду ШІ-огляду закладів харчування. Замість самостійного читання сотень відгуків, користувач отримує концентрований нейро-звіт від ШІ на основі агрегованих даних.

Замовник

Стартап The Inside Scoop

Цільова аудиторія

Туристи та місцеві мешканці у пошуку нових закладів. Вік 18+, платоспроможні люди.

02

Загальний опис

Гість

Не зареєстрований користувач. Пошук закладів, обмежений ліміт запитів до ШІ.

Зареєстрований

Пошук закладів, розширений ліміт запитів до ШІ, збереження історії.

Зовнішні залежності

DeepSeek API Google Maps Yelp PostgreSQL SMTP-сервер Amazon Cloud
03

Функціональні вимоги

FR-01MustКористувач може шукати ресторани за введеним містом.
FR-02MustРезультати пошуку відображаються списком із можливістю сортування.
FR-03MustДля кожного закладу генерується нейро-звіт на основі опису та відгуків.
FR-04MustКонтактні дані закладу доступні на сторінці перегляду.
FR-05MustКористувач може задавати уточнюючі запитання до ШІ-помічника про конкретний заклад.
FR-06MustРеєстрація та авторизація виконуються через email.
FR-07MustЗареєстрований користувач отримує більший ліміт запитів до ШІ, ніж незареєстрований.
FR-08MustКористувач може залишити оцінку закладу.
FR-09ShouldВідгуки про заклад агрегуються з відкритих джерел і відображаються на сторінці закладу.
FR-10CouldПісля реєстрації користувач отримує підтвердження на email.
04

Нефункціональні вимоги

Продуктивність

NFR-P-01Час відповіді пошуку ≤ 2 сек при 2000 одночасних користувачів.
NFR-P-02Нейро-звіт генерується за ≤ 20 сек.

Безпека

NFR-S-01Паролі зберігаються у вигляді bcrypt-хешів.
NFR-S-02HTTPS обов'язковий (TLS 1.2+), всі дані шифруються.
NFR-S-03Лімітер запитів з одного IP для захисту від brute-force.

Зручність використання

NFR-U-01Інтерфейс адаптивний для екранів від мобільного до десктопу.
NFR-U-02Підтримка Windows, Linux, macOS, Android, iOS у всіх популярних браузерах.

Надійність

NFR-R-01Uptime ≥ 99%, пріоритет у критичні години 12:00–14:00 та 18:00–21:00.
NFR-R-02Автоматичний backup БД раз на 24 год.

Масштабованість

NFR-SC-01Архітектура на Amazon Cloud дозволяє горизонтальне масштабування при зростанні навантаження.
NFR-SC-02Система витримує зростання до 10 000 користувачів без переписування архітектури.
05

Обмеження

C-01Back-end реалізується на Python (FastAPI)
C-02Розгортання — Docker-контейнери на Amazon Cloud VPS
C-03Бюджет: до $800/рік на інфраструктуру
C-04Захист персональних даних: GDPR та CCPA
06

Глосарій

MVPMinimum Viable Product — мінімальна версія продукту з базовою функціональністю для першого запуску.
GDPRРегуляторний акт ЄС щодо захисту персональних даних користувачів.
CCPAЗакон про захист персональних даних штату Каліфорнія.
VPSVirtual Private Server — віртуальний приватний сервер для розгортання застосунку.
Нейро-звітЗгенерований ШІ короткий аналіз закладу на основі агрегованих відгуків та опису.
UptimeВідсоток часу, протягом якого система доступна та працює справно.
